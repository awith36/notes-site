# notes-site

## how to run
1. Clone project or open it in a github codespace
2. open a terminal in the directory "notes site"
3. make sure python is installed
4. run: source venv/bin/activate
6. run: python server.py
7. go to the link provided

### if that dosnt work make shure the folder venv is there
- if not run this
1. python -m venv venv
2. source venv/bin/activate
3. pip install flask
4. python server.py

## required dependencies
- flask
- JSON
